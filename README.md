# quake4-360-recomp

An unofficial static recompilation of the Xbox 360 release of **Quake 4** for Windows and Linux, with native performance, a higher frame rate, and the 360 version's controller handling.

**Status:** planning. See [docs/PLAN.md](docs/PLAN.md).

This repository contains no game data. You need your own legally dumped disc; see [docs/RIPPING.md](docs/RIPPING.md).
